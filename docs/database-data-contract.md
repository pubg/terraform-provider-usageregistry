# Usage Registry 데이터 계약

Canonical 데이터 계약은 [`Devops/usageregistry-lib`](https://git.projectbro.com/Devops/usageregistry-lib/-/blob/master/docs/database-data-contract.md) 저장소로 이전했다.

이 저장소는 Terraform provider와 기존 데이터의 migration·backfill 명령을 관리한다. Provider의 storage 구현은 `usageregistry-lib` 첫 릴리스 이후 Go 패키지 의존성으로 전환한다.
